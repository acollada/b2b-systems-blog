# Consumo de APIs REST externas mediante **HttpClient** y autenticación **OAuth2**

> Este artículo está pensado para desarrolladores que ya tienen experiencia con .NET y quieren integrar servicios externos que exigen OAuth2. Se cubren los fundamentos, el flujo de trabajo completo y las buenas prácticas para que el consumo sea robusto, seguro y mantenible.

---

## 1. Requisitos previos y contexto técnico

| Elemento | Descripción | Por qué es importante |
|----------|-------------|----------------------|
| **.NET 6 / .NET 7** | Versión LTS recomendada, con soporte para `IHttpClientFactory` y `Polly`. | Proporciona APIs modernas y mejoras de rendimiento. |
| **Visual Studio 2022** / **VS Code + CLI** | Entorno de desarrollo. | Facilita la creación de proyectos y la depuración. |
| **Conocimientos básicos de OAuth2** | Entender los flujos `Client Credentials`, `Authorization Code` y `Refresh Token`. | Los endpoints de autorización y token varían según el flujo. |
| **Conocimiento de HttpClient** | Saber crear, configurar y reutilizar instancias. | Evita problemas de agotamiento de sockets y mejora el rendimiento. |
| **Acceso a la API externa** | Credenciales, URL base, scopes, y documentación del endpoint. | Necesario para generar peticiones correctas y obtener el token. |
| **Herramientas de gestión de secretos** | Azure Key Vault, AWS Secrets Manager, o variables de entorno. | Mantener las credenciales fuera del código fuente. |

> **Tip**: Si la API que vas a consumir tiene una SDK oficial, evalúa usarla primero. Si no, sigue con el enfoque `HttpClient`.

## 2. Paso a paso de implementación con listas numeradas

> En este ejemplo utilizaremos el flujo **Client Credentials** porque es el más sencillo y se adapta a la mayoría de los servicios de back‑to‑back (sin interacción del usuario). Si necesitas el flujo **Authorization Code** (con redirección y consent), los pasos son similares, solo cambia la obtención del token.

1. **Crear el proyecto**  
   ```bash
   dotnet new webapi -n OAuthClientDemo
   cd OAuthClientDemo
   ```

2. **Instalar paquetes NuGet**  
   ```bash
   dotnet add package Microsoft.Extensions.Http
   dotnet add package Polly
   dotnet add package IdentityModel
   ```
   * `Microsoft.Extensions.Http` → `IHttpClientFactory`.  
   * `Polly` → manejo de resiliencia (retry, circuit breaker).  
   * `IdentityModel` → helpers para OAuth2 (`TokenClient`, `TokenResponse`).

3. **Configurar el archivo `appsettings.json`**  
   ```json
   {
     "OAuth": {
       "TokenEndpoint": "https://auth.example.com/oauth/token",
       "ClientId": "YOUR_CLIENT_ID",
       "ClientSecret": "YOUR_CLIENT_SECRET",
       "Scope": "api.read api.write"
     },
     "ExternalApi": {
       "BaseUrl": "https://api.example.com/v1"
     }
   }
   ```

4. **Registrar servicios en `Program.cs`**  
   ```csharp
   var builder = WebApplication.CreateBuilder(args);

   // 4.1. Cargar configuración
   var oauthConfig = builder.Configuration.GetSection("OAuth");
   var apiConfig = builder.Configuration.GetSection("ExternalApi");

   // 4.2. Registrar HttpClient con Polly
   builder.Services.AddHttpClient("ExternalApi", client =>
   {
       client.BaseAddress = new Uri(apiConfig["BaseUrl"]);
       client.DefaultRequestHeaders.Accept.Add(
           new MediaTypeWithQualityHeaderValue("application/json"));
   })
   .AddPolicyHandler(Policy.Handle<HttpRequestException>().RetryAsync(3))
   .AddPolicyHandler(Policy.HandleResult<HttpResponseMessage>(r => !r.IsSuccessStatusCode).CircuitBreakerAsync(5, TimeSpan.FromSeconds(30)));

   // 4.3. Registrar el servicio de token
   builder.Services.AddSingleton<ITokenService, TokenService>();

   // 4.4. Registrar el cliente de la API externa
   builder.Services.AddScoped<IExternalApiClient, ExternalApiClient>();

   var app = builder.Build();
   // ...
   ```

5. **Crear la interfaz y la implementación del servicio de token**  
   ```csharp
   // ITokenService.cs
   public interface ITokenService
   {
       Task<string> GetAccessTokenAsync(CancellationToken ct = default);
   }

   // TokenService.cs
   public class TokenService : ITokenService
   {
       private readonly HttpClient _httpClient;
       private readonly IConfiguration _config;
       private string? _accessToken;
       private DateTimeOffset _expiresAt = DateTimeOffset.MinValue;
       private readonly SemaphoreSlim _semaphore = new(1, 1);

       public TokenService(IHttpClientFactory httpClientFactory, IConfiguration config)
       {
           _httpClient = httpClientFactory.CreateClient(); // No base address
           _config = config;
       }

       public async Task<string> GetAccessTokenAsync(CancellationToken ct = default)
       {
           // Si el token es válido, devolverlo
           if (!string.IsNullOrEmpty(_accessToken) && DateTimeOffset.UtcNow < _expiresAt)
               return _accessToken;

           // Evita que múltiples llamadas concurrentes soliciten el token al mismo tiempo
           await _semaphore.WaitAsync(ct);
           try
           {
               if (!string.IsNullOrEmpty(_accessToken) && DateTimeOffset.UtcNow < _expiresAt)
                   return _accessToken;

               var tokenEndpoint = _config["OAuth:TokenEndpoint"]!;
               var clientId = _config["OAuth:ClientId"]!;
               var clientSecret = _config["OAuth:ClientSecret"]!;
               var scope = _config["OAuth:Scope"]!;

               var request = new HttpRequestMessage(HttpMethod.Post, tokenEndpoint);
               request.Content = new FormUrlEncodedContent(new[]
               {
                   new KeyValuePair<string, string>("grant_type", "client_credentials"),
                   new KeyValuePair<string, string>("client_id", clientId),
                   new KeyValuePair<string, string>("client_secret", clientSecret),
                   new KeyValuePair<string, string>("scope", scope)
               });

               var response = await _httpClient.SendAsync(request, ct);
               response.EnsureSuccessStatusCode();

               var payload = await response.Content.ReadFromJsonAsync<TokenResponse>(cancellationToken: ct);
               _accessToken = payload?.AccessToken ?? throw new InvalidOperationException("Token vacío");
               _expiresAt = DateTimeOffset.UtcNow.AddSeconds(payload!.ExpiresIn - 60); // Buffer de 60s

               return _accessToken;
           }
           finally
           {
               _semaphore.Release();
           }
       }
   }
   ```

6. **Crear la interfaz y la implementación del cliente de la API externa**  
   ```csharp
   // IExternalApiClient.cs
   public interface IExternalApiClient
   {
       Task<T> GetAsync<T>(string endpoint, CancellationToken ct = default);
       Task<TResponse> PostAsync<TRequest, TResponse>(string endpoint, TRequest body, CancellationToken ct = default);
       // Puedes añadir PUT, DELETE, etc.
   }

   // ExternalApiClient.cs
   public class ExternalApiClient : IExternalApiClient
   {
       private readonly HttpClient _httpClient;
       private readonly ITokenService _tokenService;

       public ExternalApiClient(IHttpClientFactory httpClientFactory, ITokenService tokenService)
       {
           _httpClient = httpClientFactory.CreateClient("ExternalApi");
           _tokenService = tokenService;
       }

       private async Task SetAuthorizationHeaderAsync(CancellationToken ct)
       {
           var token = await _tokenService.GetAccessTokenAsync(ct);
           _httpClient.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);
       }

       public async Task<T> GetAsync<T>(string endpoint, CancellationToken ct = default)
       {
           await SetAuthorizationHeaderAsync(ct);
           var response = await _httpClient.GetAsync(endpoint, ct);
           response.EnsureSuccessStatusCode();
           return await response.Content.ReadFromJsonAsync<T>(cancellationToken: ct);
       }

       public async Task<TResponse> PostAsync<TRequest, TResponse>(string endpoint, TRequest body, CancellationToken ct = default)
       {
           await SetAuthorizationHeaderAsync(ct);
           var response = await _httpClient.PostAsJsonAsync(endpoint, body, ct);
           response.EnsureSuccessStatusCode();
           return await response.Content.ReadFromJsonAsync<TResponse>(cancellationToken: ct);
       }
   }
   ```

7. **Consumir el cliente en un controlador**  
   ```csharp
   // Controllers/ValuesController.cs
   [ApiController]
   [Route("[controller]")]
   public class ValuesController : ControllerBase
   {
       private readonly IExternalApiClient _apiClient;

       public ValuesController(IExternalApiClient apiClient)
       {
           _apiClient = apiClient;
       }

       [HttpGet]
       public async Task<IActionResult> Get()
       {
           var result = await _apiClient.GetAsync<List<string>>("/values");
           return Ok(result);
       }

       [HttpPost]
       public async Task<IActionResult> Post([FromBody] string newValue)
       {
           var response = await _apiClient.PostAsync<string, bool>("/values", newValue);
           return Ok(response);
       }
   }
   ```

8. **Ejecutar y probar**  
   ```bash
   dotnet run
   ```
   - Accede a `https://localhost:5001/values` (GET).  
   - Envía un POST a `https://localhost:5001/values` con un cuerpo JSON.

9. **Monitorear y depurar**  
   - Usa `ILogger` en `TokenService` y `ExternalApiClient`.  
   - Habilita logs de `HttpClient` con `AddHttpClient` → `ConfigurePrimaryHttpMessageHandler`.  
   - Configura métricas (Prometheus, Application Insights) si es necesario.

## 3. Bloque de código de ejemplo comentado

```csharp
// TokenService.cs
public class TokenService : ITokenService
{
    private readonly HttpClient _httpClient;
    private readonly IConfiguration _config;

    // Almacena el token y su expiración
    private string? _accessToken;
    private DateTimeOffset _expiresAt = DateTimeOffset.MinValue;

    // Se utiliza para evitar que múltiples hilos soliciten el token simultáneamente
    private readonly SemaphoreSlim _semaphore = new(1, 1);

    public TokenService(IHttpClientFactory httpClientFactory, IConfiguration config)
    {
        // Se crea un HttpClient sin base address; el endpoint se pasa explícitamente
        _httpClient = httpClientFactory.CreateClient();
        _config = config;
    }

    /// <summary>
    /// Obtiene un token de acceso válido. Si el token actual ha expirado,
    /// realiza una solicitud al endpoint de token.
    /// </summary>
    public async Task<string> GetAccessTokenAsync(CancellationToken ct = default)
    {
        // Si ya tenemos un token válido, retornamos
        if (!string.IsNullOrEmpty(_accessToken) && DateTimeOffset.UtcNow < _expiresAt)
            return _accessToken;

        await _semaphore.WaitAsync(ct);

        {
            // Re‑verificamos dentro del bloqueo (doble chequeo)
            if (!string.IsNullOrEmpty(_accessToken) && DateTimeOffset.UtcNow < _expiresAt)
                return _accessToken;

            // Construir la solicitud de token
            var tokenEndpoint = _config["OAuth:TokenEndpoint"]!;
            var clientId = _config["OAuth:ClientId"]!;
            var clientSecret = _config["OAuth:ClientSecret"]!;
            var scope = _config["OAuth:Scope"]!;

            var request = new HttpRequestMessage(HttpMethod.Post, tokenEndpoint);
            request.Content = new
