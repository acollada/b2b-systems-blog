# Consumo de APIs REST externas mediante HttpClient y autenticación OAuth2  

> Este artículo técnico está dirigido a desarrolladores .NET que necesitan consumir servicios REST externos protegidos por OAuth2. Se cubren los requisitos previos, una guía paso a paso, un bloque de código completo y buenas prácticas para evitar errores comunes.

---

## 1. Requisitos previos y contexto técnico

| Tema | Descripción |
|------|-------------|
| **.NET** | 7.0 (o superior). Se usa `HttpClient`, `HttpClientFactory` y `IdentityModel`. |
| **OAuth2** | Se asume el flujo **Client Credentials** (ideal para servicios sin interacción humana). |
| **Dependencias** | `Microsoft.Extensions.Http`, `IdentityModel`, `Newtonsoft.Json` (opcional). |
| **Configuración** | Se necesita un *client id*, *client secret*, *token endpoint* y el *scope* que se desea solicitar. |
| **Entorno** | Aplicación de consola, ASP.NET Core, microservicio, etc. |

> **Nota:** Si el API requiere otro flujo (Authorization Code, Implicit, Refresh Token), la lógica cambia, pero la idea de usar `HttpClientFactory` y manejar los tokens sigue siendo la misma.

---

## 2. Paso a paso de implementación con listas numeradas

1. **Crear el proyecto**  
   ```bash
   dotnet new console -n RestClientOAuth2
   cd RestClientOAuth2
   dotnet add package Microsoft.Extensions.Http
   dotnet add package IdentityModel
   dotnet add package Newtonsoft.Json
   ```

2. **Definir la configuración** (`appsettings.json`)  
   ```json
   {
     "OAuth2": {
       "TokenEndpoint": "https://auth.example.com/oauth/token",
       "ClientId": "tu-client-id",
       "ClientSecret": "tu-client-secret",
       "Scope": "api.read"
     },
     "Api": {
       "BaseUrl": "https://api.example.com/v1/"
     }
   }
   ```

3. **Crear POCOs para la configuración**  
   ```csharp
   public class OAuth2Options
   {
       public string TokenEndpoint { get; set; } = default!;
       public string ClientId { get; set; } = default!;
       public string ClientSecret { get; set; } = default!;
       public string Scope { get; set; } = default!;
   }

   public class ApiOptions
   {
       public string BaseUrl { get; set; } = default!;
   }
   ```

4. **Registrar los servicios en `Program.cs`**  
   ```csharp
   var builder = Host.CreateDefaultBuilder(args)
       .ConfigureServices((context, services) =>
       {
           // Cargar configuraciones
           services.Configure<OAuth2Options>(context.Configuration.GetSection("OAuth2"));
           services.Configure<ApiOptions>(context.Configuration.GetSection("Api"));

           // HttpClientFactory: un HttpClient por API
           services.AddHttpClient("ApiClient", client =>
           {
               client.BaseAddress = new Uri(context.Configuration["Api:BaseUrl"]);
               client.DefaultRequestHeaders.Accept.Add(new MediaTypeWithQualityHeaderValue("application/json"));
           });

           // Servicio que encapsula la lógica OAuth2
           services.AddSingleton<OAuth2TokenService>();

           // Servicio de negocio que usa el HttpClient
           services.AddTransient<ApiService>();
       });

   var host = builder.Build();
   await host.RunAsync();
   ```

5. **Implementar `OAuth2TokenService`**  
   ```csharp
   public class OAuth2TokenService
   {
       private readonly IHttpClientFactory _httpFactory;
       private readonly OAuth2Options _options;
       private readonly SemaphoreSlim _semaphore = new(1, 1);
       private string? _accessToken;
       private DateTime _expiresAt = DateTime.MinValue;

       public OAuth2TokenService(IHttpClientFactory httpFactory, IOptions<OAuth2Options> options)
       {
           _httpFactory = httpFactory;
           _options = options.Value;
       }

       public async Task<string> GetAccessTokenAsync()
       {
           // Si el token es válido, lo devolvemos
           if (!string.IsNullOrEmpty(_accessToken) && DateTime.UtcNow < _expiresAt)
               return _accessToken;

           await _semaphore.WaitAsync();
           try
           {
               // Re‑verificar dentro del lock
               if (!string.IsNullOrEmpty(_accessToken) && DateTime.UtcNow < _expiresAt)
                   return _accessToken;

               var client = _httpFactory.CreateClient();
               var tokenResponse = await client.RequestClientCredentialsTokenAsync(new ClientCredentialsTokenRequest
               {
                   Address = _options.TokenEndpoint,
                   ClientId = _options.ClientId,
                   ClientSecret = _options.ClientSecret,
                   Scope = _options.Scope
               });

               if (tokenResponse.IsError)
                   throw new InvalidOperationException($"Error al obtener token: {tokenResponse.Error}");

               _accessToken = tokenResponse.AccessToken;
               _expiresAt = DateTime.UtcNow.AddSeconds(tokenResponse.ExpiresIn - 60); // 60s buffer

               return _accessToken;
           }
           finally
           {
               _semaphore.Release();
           }
       }
   }
   ```

6. **Crear `ApiService` que usa el token**  
   ```csharp
   public class ApiService
   {
       private readonly IHttpClientFactory _httpFactory;
       private readonly OAuth2TokenService _tokenService;
       private readonly ApiOptions _apiOptions;

       public ApiService(IHttpClientFactory httpFactory, OAuth2TokenService tokenService, IOptions<ApiOptions> apiOptions)
       {
           _httpFactory = httpFactory;
           _tokenService = tokenService;
           _apiOptions = apiOptions.Value;
       }

       public async Task<T?> GetAsync<T>(string endpoint)
       {
           var client = _httpFactory.CreateClient("ApiClient");
           var token = await _tokenService.GetAccessTokenAsync();
           client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);

           var response = await client.GetAsync(endpoint);
           response.EnsureSuccessStatusCode();

           var json = await response.Content.ReadAsStringAsync();
           return JsonConvert.DeserializeObject<T>(json);
       }

       // Métodos POST, PUT, DELETE pueden añadirse de forma similar
   }
   ```

7. **Usar el servicio en `Main`**  
   ```csharp
   var host = builder.Build();
   var apiService = host.Services.GetRequiredService<ApiService>();

   var result = await apiService.GetAsync<MyDto>("resources/123");
   Console.WriteLine(JsonConvert.SerializeObject(result, Formatting.Indented));

   await host.RunAsync();
   ```

## 3. Bloque de código de ejemplo comentado

```csharp
// OAuth2Options.cs
public class OAuth2Options
{
    public string TokenEndpoint { get; set; } = default!;
    public string ClientId { get; set; } = default!;
    public string ClientSecret { get; set; } = default!;
    public string Scope { get; set; } = default!;
}

// ApiOptions.cs
public class ApiOptions
{
    public string BaseUrl { get; set; } = default!;
}

// OAuth2TokenService.cs
public class OAuth2TokenService
{
    private readonly IHttpClientFactory _httpFactory;
    private readonly OAuth2Options _options;
    private readonly SemaphoreSlim _semaphore = new(1, 1);
    private string? _accessToken;
    private DateTime _expiresAt = DateTime.MinValue;

    public OAuth2TokenService(IHttpClientFactory httpFactory, IOptions<OAuth2Options> options)
    {
        _httpFactory = httpFactory;
        _options = options.Value;
    }

    // Devuelve un token válido, solicitando uno nuevo si es necesario
    public async Task<string> GetAccessTokenAsync()
    {
        if (!string.IsNullOrEmpty(_accessToken) && DateTime.UtcNow < _expiresAt)
            return _accessToken;

        await _semaphore.WaitAsync();
        try
        {
            if (!string.IsNullOrEmpty(_accessToken) && DateTime.UtcNow < _expiresAt)
                return _accessToken;

            var client = _httpFactory.CreateClient();
            var tokenResponse = await client.RequestClientCredentialsTokenAsync(new ClientCredentialsTokenRequest
            {
                Address = _options.TokenEndpoint,
                ClientId = _options.ClientId,
                ClientSecret = _options.ClientSecret,
                Scope = _options.Scope
            });

            if (tokenResponse.IsError)
                throw new InvalidOperationException($"Error al obtener token: {tokenResponse.Error}");

            _accessToken = tokenResponse.AccessToken;
            // Guardamos el tiempo de expiración con un buffer de 60s
            _expiresAt = DateTime.UtcNow.AddSeconds(tokenResponse.ExpiresIn - 60);

            return _accessToken;
        }
        finally
        {
            _semaphore.Release();
        }
    }
}

// ApiService.cs
public class ApiService
{
    private readonly IHttpClientFactory _httpFactory;
    private readonly OAuth2TokenService _tokenService;
    private readonly ApiOptions _apiOptions;

    public ApiService(IHttpClientFactory httpFactory, OAuth2TokenService tokenService, IOptions<ApiOptions> apiOptions)
    {
        _httpFactory = httpFactory;
        _tokenService = tokenService;
        _apiOptions = apiOptions.Value;
    }

    public async Task<T?> GetAsync<T>(string endpoint)
    {
        var client = _httpFactory.CreateClient("ApiClient");
        var token = await _tokenService.GetAccessTokenAsync();
        client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);

        var response = await client.GetAsync(endpoint);
        response.EnsureSuccessStatusCode();

        var json = await response.Content.ReadAsStringAsync();
        return JsonConvert.DeserializeObject<T>(json);
    }
}
```

> **Explicación rápida**  
> * `OAuth2TokenService` gestiona el ciclo de vida del token, evitando peticiones concurrentes con `SemaphoreSlim`.  
> * `ApiService` encapsula la lógica de llamadas HTTP y se reutiliza en toda la aplicación.  
> * `HttpClientFactory` garantiza que los `HttpClient` se reciclen y no se agoten sockets.

## 4. Buenas prácticas y errores comunes a evitar

| Buenas prácticas | Por qué son importantes |
|-------------------|-------------------------|
| **Usar `IHttpClientFactory`** | Evita *socket exhaustion*, gestiona la vida de `HttpClient` y permite configurar políticas de resiliencia (retry, circuit breaker). |
| **Cachear el token** | Reduce latencia y evita sobrecargar el servidor de autorización. |
| **Evitar `new HttpClient()`** | Cada instancia abre nuevos sockets; con muchas llamadas puede agotar recursos. |
| **Configurar timeouts y políticas** | `HttpClient.Timeout`, `RetryPolicy` (Polly) y `CircuitBreaker` mejoran la robustez. |
| **Separar responsabilidades** | `OAuth2TokenService` solo se encarga del token; `ApiService` solo de la lógica de negocio. |
| **Validar respuestas** | Usar `EnsureSuccessStatusCode()` y manejar códigos 4xx/5xx adecuadamente. |
| **Loggear de forma segura** | No registrar el token ni credenciales en logs. |
| **Usar TLS 1.2/1.3** | Configurar `ServicePointManager.SecurityProtocol` o usar `HttpClientHandler.SslProtocols`. |
| **Revisar scopes** | Pedir solo los scopes necesarios para minimizar privilegios. |

### Errores comunes

| Error | Solución |
|-------|----------|
| **Token caducado sin refrescar** | Implementar lógica de refresco (como en el ejemplo) o usar `TokenResponse.IsError`. |
| **Excepciones de `SocketException`** | Usar `IHttpClientFactory` o aumentar el pool de sockets con `HttpClientHandler.MaxConnectionsPerServer`. |
| **Fallo en `EnsureSuccessStatusCode()` sin manejo** | Capturar `HttpRequestException`, analizar `StatusCode` y decidir reintentos o fallos. |
| **Exponer el `client_secret`** | Guardar en *Azure Key Vault*, *AWS Secrets Manager* o `appsettings.json` con `User Secrets` en dev. |
| **No usar `async/await`** | Bloquea hilos y provoca deadlocks en UI o ASP.NET. |
| **No configurar `Accept`** | El servidor puede devolver XML o texto; establecer `application/json` garantiza el formato. |

## Resumen

1. **Configura** tus credenciales y endpoints en `appsettings.json`.  
2. **Registra** `HttpClientFactory`, `OAuth2TokenService` y `ApiService` en el contenedor DI.  
3. **Implementa** la lógica de token con caching y concurrency control.  
4. **Consume** la API a través de `ApiService`, que se encarga de la autenticación y la serialización.  
5. **Aplica** buenas prácticas y evita los errores listados.
