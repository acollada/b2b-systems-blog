# Integración Robusta con Servicios Externos: HttpClient y Manejo de Errores en Business Central

## 1. Requisitos Previos, Contexto Técnico y Arquitectura

### Contexto Técnico
En el ecosistema de Microsoft Dynamics 365 Business Central, la conectividad con sistemas de terceros (APIs REST, Web Services SOAP, Pasarelas de Pago, etc.) es una necesidad fundamental. El objeto de código `HttpClient` representa la abstracción moderna y recomendada para realizar peticiones HTTP en el lenguaje AL.

A diferencia de los antiguos objetos `WebClient` o `HttpMessage`, `HttpClient` ofrece:
*   **Gestión de Sesiones**: Capacidad de mantener cookies y estados de autenticación a lo largo de múltiples peticiones.
*   **Soporte Nativo para HTTP/2**: Mejora en el rendimiento de red.
*   **Integración con TLS**: Configuración flexible de versiones de TLS y certificados.
*   **Modelo Sincrono/Abrupto**: Opera de forma síncrona, lo que exige una cuidadosa gestión del tiempo de espera (timeouts) para no bloquear el thread de la aplicación.

### Arquitectura de la Solución
Para una implementación escalable, se recomienda una arquitectura en capas:

1.  **Capa de Presentación/Trigger**: Inicia la integración (ej. al guardar un documento o mediante un botón de acción).
2.  **Capa de Servicio (Codeunit)**: Contiene la lógica de negocio y coordina la llamada HTTP.
3.  **Capa de Cliente HTTP (Codeunit específica o variable local)**: Encapsula la configuración de `HttpClient`, manejo de encabezados y ejecución de la petición.
4.  **Capa de Manejo de Errores**: Centraliza la interpretación de códigos de estado HTTP y respuestas del servidor.

### Requisitos Previos
*   **Licencia**: Business Central Premium o la funcionalidad específica habilitada (dependiendo de la extensión).
*   **Conocimiento de AL**: Familiaridad con objetos de código, variables de tipo `Text`, `Integer`, `JsonToken`, y manejo de excepciones (`Try/Catch`).
*   **Acceso de Red**: Verificar que los puertos 80/443 estén abiertos desde el servidor de BC hacia el endpoint externo.
*   **Certificados**: Si el servicio externo usa autenticación mutua (mTLS), se requiere importar el certificado en el entorno de BC.

## 2. Paso a Paso de Implementación en AL

Sigue estos pasos para implementar una llamada HTTP segura y robusta:

1.  **Crear un Codeunit de Servicio**: Crea un objeto de código dedicado (ej. `50000 ExternalAPIConnector`) para encapsular la lógica de la API.
2.  **Declarar Variables**:
    *   Instancia de `HttpClient`.
    *   `HttpRequestMessage` para construir la petición.
    *   `HttpResponseMessage` para capturar la respuesta.
    *   Variables para Almacenar estado HTTP (`Integer`) y cuerpo de respuesta (`Text`).
3.  **Configurar el HttpClient**:
    *   Establecer `Timeout` (recomendado: 30-60 segundos para evitar bloqueos largos).
    *   Configurar `AllowAutoRedirect` si la API redirige a otro dominio.
    *   (Opcional) Configurar `TlsVersions` si el servicio usa una versión específica de TLS.
4.  **Construir la Petición**:
    *   Crear un `HttpRequestMessage`.
    *   Definir el método (`GET`, `POST`, `PUT`, `DELETE`).
    *   Establecer la URI completa.
    *   Agregar encabezados críticos (`Content-Type`, `Accept`, `Authorization`).
    *   Para `POST`/`PUT`, añadir el cuerpo de la solicitud (JSON, XML, Form-Data).
5.  **Ejecutar la Solicitud**:
    *   Usar el método `Send()` del `HttpClient`.
    *   Capturar el `HttpResponseMessage`.
6.  **Manejo de Respuesta y Errores**:
    *   Verificar el `StatusCode` de la respuesta.
    *   Si el estado es exitoso (2xx), leer el cuerpo (`ReadAsText()`).
    *   Si el estado es de error (4xx, 5xx), leer el cuerpo para obtener detalles del error y lanzar una excepción controlada o registrar un error.
7.  **Parseo de Datos**: Convertir el texto de respuesta (JSON) en tokens para extraer los campos necesarios.

## 3. Bloque de Código AL de Ejemplo

```al
codeunit 50000 "ExternalAPIConnector"
{
    procedure SendPostRequest(targetUri: Text; jsonData: Text): Text
    var
        httpClient: HttpClient;
        requestMessage: HttpRequestMessage;
        responseMessage: HttpResponseMessage;
        responseText: Text;
        statusCode: Integer;
        contentType: Text;
    begin
        // 1. Configuración del Cliente HTTP
        // Configurar timeout para evitar bloqueos indefinidos
        httpClient.Timeout(Duration::Minutes(1));
        httpClient.AllowAutoRedirect(true);

        // 2. Construcción de la Petición
        requestMessage.Method(HttpVerb::Post);
        requestMessage.Uri(CreateUri(targetUri));

        // 3. Encabezados de la Peticion
        requestMessage.Headers.Add('Content-Type', 'application/json');
        requestMessage.Headers.Add('Accept', 'application/json');
        // Ejemplo de autenticación Bearer Token (reemplazar con lógica real)
        requestMessage.Headers.Add('Authorization', 'Bearer ' + GetAuthToken());

        // 4. Cuerpo de la Solicitud
        // Verificar que el JSON sea válido antes de enviar
        if Not ValidateJson(jsonData) then
            Error('El cuerpo de la solicitud no es un JSON válido.');

        requestMessage.Content(BlobToTextBlob(jsonData));

        // 5. Ejecución y Manejo de Respuesta
        try
            // Enviar la solicitud y capturar la respuesta
            httpClient.Send(requestMessage, responseMessage);

            // Verificar el código de estado HTTP
            statusCode := responseMessagegetStatusCode();

            // Leer el cuerpo de la respuesta
            responseText := responseMessage.Content().ReadAsText();

            // 6. Lógica de Manejo de Errores Basado en Estado HTTP
            case statusCode of
                200..299:
                    // Éxito: Devolver el cuerpo de la respuesta
                    if responseText = '' then
                        Error('Respuesta vacía del servidor.');
                    exit(responseText);

                401:
                    Error('Error 401: Autenticación fallida. Verifica las credenciales.');
                403:
                    Error('Error 403: Acceso denegado. Verifica permisos.');
                404:
                    Error('Error 404: Recurso no encontrado en la API externa.');
                429:
                    Error('Error 429: Demasiadas solicitudes. Inténtalo más tarde (Rate Limiting).');
                500..599:
                    Error('Error del Servidor (5xx): ' + responseText);
                else:
                    // Error desconocido
                    Error('Código de estado HTTP inesperado: ' + Format(statusCode) + '. Respuesta: ' + responseText);
            end;

        catch
            // Manejo de excepciones de red (timeout, DNS, conexión negada)
            if GetLastErrorText() <> '' then
                Error('Error de red al conectar con la API externa: ' + GetLastErrorText());
        end;
    end;

    local procedure CreateUri(targetUri: Text): Uri
    begin
        // Validación básica de la URI
        if Not Uri::IsValidUri(targetUri) then
            Error('La URI proporcionada no es válida: ' + targetUri);
        exit(targetUri);
    end;

    local procedure GetAuthToken(): Text
    var
        config: Record "Extension Configuration";
    begin
        // Ejemplo: Obtener token desde configuración o servicio de identidad
        if Not config.Get('API_TOKEN') then
            Error('Token de API no configurado.');
        exit(config.Value);
    end;

    local procedure ValidateJson(jsonText: Text): Boolean
    var
        jsonToken: JsonToken;
    begin
        if Not Json::Parse(jsonToken, jsonText) then
            exit(false);
        exit(true);
    end;

    local procedure BlobToTextBlob(text: Text): Blob
    var
        blob: Blob;
        outStream: OutStream;
    begin
        CreateOutStream(blob);
        outStream.Write(text);
        exit(blob);
    end;
}
```

### Notas sobre el Código:
*   **Timeout**: Se establece a 1 minuto. Ajustar según la latencia esperada de la API externa.
*   **Try/Catch**: Captura errores de red (excepciones del sistema) separados de los errores de aplicación (códigos HTTP).
*   **Validación JSON**: Se valida el JSON
