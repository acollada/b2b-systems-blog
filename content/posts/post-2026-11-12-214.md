# Consumo de APIs REST externas mediante **HttpClient** y autenticación **OAuth2**

> **Objetivo**  
> Proveer una guía completa y práctica para consumir APIs REST externas en .NET utilizando `HttpClient` y autenticación OAuth2 (Client Credentials Flow).  
> La documentación está pensada para desarrolladores con conocimientos intermedios de C# y patrones de diseño de aplicaciones .NET.

---

## 1. Requisitos previos y contexto técnico

| Elemento | Requisito | Comentario |
|----------|-----------|------------|
| **.NET** | .NET 6 o superior | `HttpClient` y `IHttpClientFactory` son parte del framework base. |
| **SDK de OAuth2** | **IdentityModel** (`Microsoft.IdentityModel.Protocols.OpenIdConnect`) | Simplifica la obtención de tokens y la configuración de `HttpClient`. |
| **API externa** | Endpoint que soporte OAuth2 (Client Credentials, Authorization Code, etc.) | Debe exponer un token endpoint (`/oauth/token`) y recursos protegidos (`/api/...`). |
| **Credenciales** | Client ID, Client Secret y Scope(s) | Se obtienen en el panel de administración de la API o del proveedor de identidad. |
| **Herramientas** | Visual Studio 2022/2023 o VS Code + .NET CLI | Para compilar y ejecutar el proyecto. |
| **Patrón** | **IHttpClientFactory** | Evita problemas de socket exhaustion y facilita la inyección de dependencias. |

> **Nota**: Si la API utiliza otro flujo OAuth2 (Authorization Code, Implicit, etc.), el patrón de obtención de token cambiará, pero la configuración de `HttpClient` sigue siendo la misma.

## 2. Paso a paso de implementación

### 2.1. Crear un proyecto de consola (o Web API)

```bash
dotnet new console -n RestClientDemo
cd RestClientDemo
```

### 2.2. Instalar paquetes NuGet

```bash
dotnet add package Microsoft.Extensions.Http
dotnet add package IdentityModel
dotnet add package Polly
```

- `Microsoft.Extensions.Http` → `IHttpClientFactory`
- `IdentityModel` → helpers para OAuth2
- `Polly` → resiliencia y retries

### 2.3. Configurar la appsettings.json

```json
{
  "OAuth": {
    "Authority": "https://auth.example.com",
    "ClientId": "my-client-id",
    "ClientSecret": "my-client-secret",
    "Scope": "api.read"
  },
  "Api": {
    "BaseUrl": "https://api.example.com"
  }
}
```

> **Seguridad**: En producción, almacena las credenciales en un almacén seguro (Azure Key Vault, AWS Secrets Manager, etc.) y no en texto plano.

### 2.4. Registrar servicios en `Program.cs`

```csharp
using System.Net.Http.Headers;
using IdentityModel.Client;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;

var builder = Host.CreateDefaultBuilder(args);

builder.ConfigureServices((context, services) =>
{
    // 1. Cargar configuración
    var oauthSettings = context.Configuration.GetSection("OAuth");
    var apiSettings = context.Configuration.GetSection("Api");

    // 2. Registrar HttpClient para la API con política de resiliencia
    services.AddHttpClient<IApiClient, ApiClient>(client =>
    {
        client.BaseAddress = new Uri(apiSettings["BaseUrl"]);
        client.DefaultRequestHeaders.Accept.Add(new MediaTypeWithQualityHeaderValue("application/json"));
    })
    .AddPolicyHandler(Policy
        .Handle<HttpRequestException>()
        .WaitAndRetryAsync(new[]
        {
            TimeSpan.FromSeconds(1),
            TimeSpan.FromSeconds(2),
            TimeSpan.FromSeconds(4)
        }));

    // 3. Registrar el servicio de token
    services.AddSingleton<ITokenService>(sp =>
        new TokenService(oauthSettings["Authority"],
                         oauthSettings["ClientId"],
                         oauthSettings["ClientSecret"],
                         oauthSettings["Scope"]));
});

await builder.RunConsoleAsync();
```

### 2.5. Definir interfaces y clases

```csharp
// ITokenService.cs
public interface ITokenService
{
    Task<string> GetAccessTokenAsync();
}

// TokenService.cs
public class TokenService : ITokenService
{
    private readonly string _authority;
    private readonly string _clientId;
    private readonly string _clientSecret;
    private readonly string _scope;
    private string? _cachedToken;
    private DateTimeOffset _expiresAt = DateTimeOffset.MinValue;

    public TokenService(string authority, string clientId, string clientSecret, string scope)
    {
        _authority = authority;
        _clientId = clientId;
        _clientSecret = clientSecret;
        _scope = scope;
    }

    public async Task<string> GetAccessTokenAsync()
    {
        // Si el token está vigente, devolverlo
        if (_cachedToken != null && DateTimeOffset.UtcNow < _expiresAt)
            return _cachedToken;

        // Obtener nuevo token
        var client = new HttpClient();
        var disco = await client.GetDiscoveryDocumentAsync(_authority);
        if (disco.IsError)
            throw new HttpRequestException($"Discovery error: {disco.Error}");

        var tokenResponse = await client.RequestClientCredentialsTokenAsync(new ClientCredentialsTokenRequest
        {
            Address = disco.TokenEndpoint,
            ClientId = _clientId,
            ClientSecret = _clientSecret,
            Scope = _scope
        });

        if (tokenResponse.IsError)
            throw new HttpRequestException($"Token error: {tokenResponse.Error}");

        _cachedToken = tokenResponse.AccessToken;
        _expiresAt = DateTimeOffset.UtcNow.AddSeconds(tokenResponse.ExpiresIn - 60); // 1 min buffer

        return _cachedToken;
    }
}

// IApiClient.cs
public interface IApiClient
{
    Task<T?> GetAsync<T>(string endpoint);
    Task<T?> PostAsync<T>(string endpoint, object body);
}

// ApiClient.cs
public class ApiClient : IApiClient
{
    private readonly HttpClient _httpClient;
    private readonly ITokenService _tokenService;

    public ApiClient(HttpClient httpClient, ITokenService tokenService)
    {
        _httpClient = httpClient;
        _tokenService = tokenService;
    }

    private async Task EnsureAuthorizedAsync()
    {
        var token = await _tokenService.GetAccessTokenAsync();
        _httpClient.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);
    }

    public async Task<T?> GetAsync<T>(string endpoint)
    {
        await EnsureAuthorizedAsync();
        var response = await _httpClient.GetAsync(endpoint);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<T>();
    }

    public async Task<T?> PostAsync<T>(string endpoint, object body)
    {
        await EnsureAuthorizedAsync();
        var response = await _httpClient.PostAsJsonAsync(endpoint, body);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<T>();
    }
}
```

### 2.6. Consumir la API desde el `Main`

```csharp
// Program.cs (continuación)
builder.ConfigureServices((context, services) =>
{
    // ... anteriores
    services.AddHostedService<Worker>();
});

public class Worker : BackgroundService
{
    private readonly IApiClient _apiClient;

    public Worker(IApiClient apiClient)
    {
        _apiClient = apiClient;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        // Ejemplo GET
        var users = await _apiClient.GetAsync<List<User>>("/users");
        Console.WriteLine($"Usuarios recibidos: {users?.Count ?? 0}");

        // Ejemplo POST
        var newUser = new { Name = "Juan", Email = "juan@example.com" };
        var created = await _apiClient.PostAsync<User>("/users", newUser);
        Console.WriteLine($"Usuario creado: {created?.Id}");
    }
}

// Modelos de ejemplo
public class User
{
    public int Id { get; set; }
    public string Name { get; set; } = default!;
    public string Email { get; set; } = default!;
}
```

## 3. Bloque de código de ejemplo comentado

```csharp
// TokenService.cs – Obtiene y almacena en caché el token OAuth2
public class TokenService : ITokenService
{
    private readonly string _authority;   // URL del servidor de autorización
    private readonly string _clientId;    // ID del cliente registrado
    private readonly string _clientSecret; // Secreto del cliente
    private readonly string _scope;       // Scope(s) solicitados
    private string? _cachedToken;         // Token en caché
    private DateTimeOffset _expiresAt;    // Expiración del token

    public TokenService(string authority, string clientId, string clientSecret, string scope)
    {
        _authority = authority;
        _clientId = clientId;
        _clientSecret = clientSecret;
        _scope = scope;
    }

    public async Task<string> GetAccessTokenAsync()
    {
        // Si el token actual no ha expirado, usarlo
        if (_cachedToken != null && DateTimeOffset.UtcNow < _expiresAt)
            return _cachedToken;

        // Descubrir endpoints del servidor de autorización
        var client = new HttpClient();
        var disco = await client.GetDiscoveryDocumentAsync(_authority);
        if (disco.IsError)
            throw new HttpRequestException($"Error de discovery: {disco.Error}");

        // Solicitar token con Client Credentials
        var tokenResponse = await client.RequestClientCredentialsTokenAsync(new ClientCredentialsTokenRequest
        {
            Address = disco.TokenEndpoint,
            ClientId = _clientId,
            ClientSecret = _clientSecret,
            Scope = _scope
        });

        if (tokenResponse.IsError)
            throw new HttpRequestException($"Error de token: {tokenResponse.Error}");

        // Cachear token y fecha de expiración (un minuto antes)
        _cachedToken = tokenResponse.AccessToken;
        _expiresAt = DateTimeOffset.UtcNow.AddSeconds(tokenResponse.ExpiresIn - 60);

        return _cachedToken;
    }
}
```

## 4. Buenas prácticas y errores comunes a evitar

| Buenas prácticas | Por qué importa | Qué evitar |
|------------------|-----------------|------------|
| **Usar `IHttpClientFactory`** | Evita *socket exhaustion* y permite configurar políticas de resiliencia. | Instanciar `new HttpClient()` manualmente. |
| **Cachear el token** | Minimiza llamadas al token endpoint y reduce latencia. | Solicitar un token en cada petición. |
| **Manejar expiración de token** | Evita errores 401 inesperados. | No comprobar la validez del token antes de usarlo. |
| **Políticas de retry y circuit breaker** | Hace la aplicación más robusta frente a fallos transitorios. | No implementar resiliencia; fallas de red se traducen en caídas. |
| **Almacenar secretos fuera del código** | Evita exponer credenciales en repositorios. | Hardcodear Client ID/Secret. |
| **Usar HTTPS siempre** | Protege la transmisión de datos sensibles. | Llamar a endpoints HTTP no seguros. |
| **Validar respuestas** | Maneja correctamente códigos de error y payloads inesperados. | Asumir que la respuesta siempre es 200 OK. |
| **Escalar la configuración de `HttpClient`** | Ajustar tiempo de espera, número máximo de conexiones, etc. | Usar valores por defecto que pueden ser insuficientes. |
| **Seguir el flujo OAuth2 correcto** | El flujo de autorización depende de la API. | Forzar un flujo que la API no soporte. |
| **Desplegar con TLS 1.2/1.3** | Compatibilidad y seguridad. | Permitir versiones antiguas de TLS. |
